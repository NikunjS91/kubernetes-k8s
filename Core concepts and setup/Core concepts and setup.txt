kubernetes architecture:
1 master node and one worker node.
master node is headquater send work to worker node.
worker node runs the docker containers, and they are managed at master node.
master node contains services:
    api server : keeps the track of work happining at worker node as well as master node.(like a team lead) 
        a communication gateway between components. meaning direct communication wont work in case need to contact the cluster can be done with api server.
    like Hiring manager we have a service called scheduler which scheduler the container at worker node
        it work is to scheduler container or pods. pods are the unit inside it containers are running.
    etcs: is the database in k8s which keep the track or scheduler task(key value pair) keep stored data of k8s in etcd.
    like project manager we have a controller manager who check everthing is working(node, pod, cluster,services)

worker node services:
    kublet is another manager who works at worker node level.check pods working or not and tells the api server and he updated the scheduler ,etcd and controller manager.
    well the pods are not accessable its actally isolated, well to access the pod outside user so the need of service proxy is there.
        with the help of service proxy it talk to api server and he later talks to kubelet and then we can access the pod.

all these nodes and masters nodes located away communication with each other with CNI network(container network interface) eg. weav Net, Calico, etc.
kubectl talk to api server and keep the track of entire k8s cluster,

    # ----------------------------
# 2. Install Kind (based on architecture)
# ----------------------------
if ! command -v kind &>/dev/null; then
  echo "📦 Installing Kind..."

  ARCH=$(uname -m)
  if [ "$ARCH" = "x86_64" ]; then
    curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.29.0/kind-linux-amd64
  elif [ "$ARCH" = "aarch64" ]; then
    curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.29.0/kind-linux-arm64
  else
    echo "❌ Unsupported architecture: $ARCH"
    exit 1
  fi

  chmod +x ./kind
  sudo mv ./kind /usr/local/bin/kind
  echo "✅ Kind installed successfully."
else
  echo "✅ Kind is already installed."
fi

# ----------------------------
# 3. Install kubectl (based on architecture)
# ----------------------------
if ! command -v kubectl &>/dev/null; then
  echo "📦 Installing kubectl (latest stable version)..."

  ARCH=$(uname -m)
  VERSION=$(curl -Ls https://dl.k8s.io/release/stable.txt)

  if [ "$ARCH" = "x86_64" ]; then
    curl -Lo ./kubectl "https://dl.k8s.io/release/${VERSION}/bin/linux/amd64/kubectl"
  elif [ "$ARCH" = "aarch64" ] || [ "$ARCH" = "arm64" ]; then
    curl -Lo ./kubectl "https://dl.k8s.io/release/${VERSION}/bin/linux/arm64/kubectl"
  else
    echo "❌ Unsupported architecture: $ARCH"
    exit 1
  fi

  chmod +x ./kubectl
  sudo mv ./kubectl /usr/local/bin/kubectl
  echo "✅ kubectl installed successfully."
else
  echo "✅ kubectl is already installed."
fi
